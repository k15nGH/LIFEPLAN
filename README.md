# 人生設計簿 — Life Plan Ledger

家族のライフプランをブラウザだけでシミュレーションする単一HTMLツール。

## できること
- リタイア年齢をスライダーで選ぶと、**その年に必要な資産（自動逆算・インフレ込み）** と **予測資産** を比較して「達成／不足」を判定。40〜60歳の早見表つき
- 成功確率（モンテカルロ400試行・利回りのブレσ）／資産が尽きる歳／初年度の取り崩し率を自動表示
- 表示は「タブ」と「縦一覧」を切替可。スマホでは各表がカード型レイアウトに自動変形
- 「レポート」ボタンで家族会議用の1枚レポートを生成し、印刷画面からPDF保存・共有可能
- 図一〜図四: 資産の推移（資産＋純資産）／年間キャッシュフロー／**資産の内訳（人別・種類別）**／**ローン残高の返済推移**
- **ローンは何本でも登録可**（住宅・車・奨学金…）。残高・月返済・金利から完済予定を自動計算
- **資産は持ち主（私・妻・子ども・共有）と種類**（現金・外貨$・投資・保険積立ほか）で登録。外貨は為替で自動円換算
- **インフレ率**を設定すると生活費・教育費・目標費用・不動産/事業収入・年金が将来価格に伸びる。給与は昇給率で別管理
- 公的年金（開始年齢・年額）と海外赴任期間（貯蓄ブースト）を織り込み
- やりたいことリスト（単発／毎年）を**チェックの付け外しで計算に含めたり外したり**
- 子どもの生まれ年から大学費用（18〜21歳・4分割）を自動計上
- 年次明細（年ごとの収支・資産・純資産・出来事）を一覧表示
- 入力はタブ式（基本／資産と家族／ローン／収入の柱／やりたいこと）

## 公開手順（GitHub Pages）
1. 新しいリポジトリを作り、`index.html`・`README.md`・`.gitignore` をpush
2. Settings → Pages → Branch: `main` / root → Save
3. 表示されたURLにアクセス
4. スマホでそのURLを開き「ホーム画面に追加」すると、専用アイコン付きでアプリのように使えます

## プライバシー設計（重要）
- **ソースコードに個人データは一切入っていません**（初期値はダミーのサンプル値）。リポジトリは公開でも安全です
- 入力した数字は**この端末のブラウザ（localStorage）にだけ**自動保存され、どこにも送信されません
- バックアップは「暗号化して書き出す」推奨（AES-GCM＋パスワード）。書き出したJSONは `.gitignore` 済みですが、**リポジトリにコミットしない**でください
- 画面共有・撮影時は「金額を隠す」ボタンで数値もグラフもぼかせます
- 旧バージョンのデータ（v1のJSON・自動保存）は読み込み時に自動で新形式へ移行されます
